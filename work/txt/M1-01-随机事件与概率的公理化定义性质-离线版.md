## 描述随机现象的几个概念

随机试验

结果不确定，但可能结果的范围是确定的

例：抽一次盲盒

样本点

每一个可能的具体结果

例：抽到量子喵

样本空间

全体样本点组成的集合， 记作$\(\Omega\)$

例：Ω = {量子喵, 甜心喵, 像素喵, 拿铁喵, 花艺喵, 齿轮喵, 星际喵, 龙焰喵, 大圣喵}

随机事件

样本点组成的集合

一般用大写英文字母表示

例：事件A；SR = {齿轮喵, 星际喵}

## 事件关系1

互斥

两事件无法同时发生，AKA不相容

$\(A\cap B=\varnothing\)$

例：抽到R与抽到SSR互斥

包含

若A发生则B一定发生，称A包含于B

$\(A \subset B\)$ （注意与$\(a\in A\)$区分）

例： {量子喵} $\(\subset\)$ 抽到R

 Ω A B

## 事件关系2

对立

A，B有且仅有一个发生

$\(A \cup B = \Omega, A \cap B= \varnothing\)$

例：「抽到 R」 与「没抽到 R」对立

分割

一系列互斥事件，其并集等于$\(\Omega\)$，称其构成对$\(\Omega\)$的分割，AKA划分

$\(A_i\cap A_j = \varnothing, \cup_i A_i = \Omega\)$

例：R、SR、SSR、UR构成对$\(\Omega\)$的划分

# 2. 定义概率

概率是满足一定性质的实值函数

（教材1.2、1.3部分）

## 概率的公理化定义

概率是定义在事件集合^1上的、满足下列性质的实值函数。

- 非负：$\(P(A) \ge 0\)$

- 正则：$\(P(\Omega) = 1\)$

- 可列可加： $\(A_1, A_2,\cdots\)$ 是互斥事件， $\(P(\cup_{i=1}^\infty A_i) = \sum_{i=1}^\infty P(A_i)\)$

事件A的概率，记为$\(P(A)\)$

🔎 对于满足前述定义的概率，下列描述合理吗？

- 事件A的概率大于1

- 事件A的概率是负数

- 事件A的概率是0

- $\(A\subset B\)$，则$\(P(A)\geq P(B)\)$（$\(A\)$包含于$\(B\)$时，$\(A\)$的概率不小于$\(B\)$）

## 概率的性质

- $\(P(\varnothing) = 0\)$

- $\(P(\overline{A}) = 1 - P(A)\)$

- $\(A \subset B \Rightarrow P(A) \le P(B)\)$（单调性）

- $\(P(A - B) = P(A) - P(AB)\)$（减法公式）

- $\(P(A \cup B) = P(A) + P(B) - P(AB)\)$（加法公式）

- $\(P(A \cup B) \le P(A) + P(B), P(\cup_{i=1}^\infty A_i) \leq \sum_{i=1}^\infty P(A_i)\)$（半可加）

维恩图能帮你理解这些性质

## 例1.3.5（1）：至少发生一个

$\(P(A)=P(B)=P(C)=\frac14\)$，$\(P(AB)=0\)$，$\(P(AC)=P(BC)=\frac1{16}\)$

解：三个事件的加法公式 $\(P(A \cup B \cup C) = \frac34 - P(AB) - P(AC) - P(BC) + P(ABC)\)$ $\(= \frac34 - 0 - \frac1{16} - \frac1{16} + 0 = \mathbf{\frac58}\)$

## 例1.3.5（2）：都不发生

$\(P(A)=P(B)=P(C)=\frac14\)$，$\(P(AB)=0\)$，$\(P(AC)=P(BC)=\frac1{16}\)$

解： $\(1 - P(A \cup B \cup C) = 1 - \frac58 = \mathbf{\frac38}\)$
